**Contradictions found and resolved during analysis** (kept for audit):

1. `{}` vs `frac()`: test suite and code disagree superficially; resolved by reading the actual node wiring — `{}` → `fractional_part()` (floor-based), `frac()` → `fractional_component()` (trunc-based); confirmed `mpfr_frac` is trunc-based via direct library probe (MPFR 4.2.2).
2. Dogtail error strings vs source strings (OQ-01).
3. Converter visibility: help pages imply converter panels in financial/advanced; source shows a single conversion-mode-only panel — source wins (also matches help notes "must be performed using the keyboard or using the conversion mode").
4. `leading_digits` 12 vs "accuracy" assumption — no link found; recorded as OQ-03.
5. `window-position` schema key exists but is never written — dead key documented (STATE-001).
